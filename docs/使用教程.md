# 墨台使用教程

> 面向日常使用。产品理念见根目录 [README](../README.md)；开发搭建见 [README · 快速开始](../README.md#快速开始开发)。

在线体验：[https://vibeholding.pages.dev](https://vibeholding.pages.dev)  
本地预览：`pnpm --filter @vh/desktop dev`（浏览器）或 `pnpm --filter @vh/desktop tauri:dev`（桌面窗口，需 Rust）。

---

## 1. 界面地图

| 入口 | 做什么 |
| --- | --- |
| **首页** | 驾驶舱：续读航线、最近更新、快捷进入知识库 / 图谱 / 方案 |
| **知识库** | 按卷浏览、筛选、详情、关联、收藏、笔记、踩坑 |
| **图谱** | 关系拓扑：焦点邻域、生态全景、替代族、依赖 DAG… |
| **方案** | 方案模板、选型向导、我的技术栈 |
| **对比** | 最多 4 列并观，差异行赭石高亮 |
| **情报** | 更新流、关注、待确认草稿、待复核 |
| **凭据** | 仅桌面 Tauri：本地加密保险库（Web / 窄屏隐藏） |
| **设置** | 主题（浅色 / 深色）、密度、组件预览入口 |

顶栏搜索或 **⌘K**（Windows / Linux：`Ctrl+K`）可直达任意分区与条目。

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `⌘K` / `Ctrl+K` | 命令面板：跳转、搜条目、切换主题、收藏 / 关注 / 对比 |
| `⌘B` / `Ctrl+B` | 知识库内开关分类抽屉 |
| `⌘\` / `Ctrl+\` | 折叠 / 展开条目列表栏 |
| 顶栏主题图标 | 深色 ↔ 浅色（也可在设置或 ⌘K「切换明暗主题」） |

## 2. 五分钟上手

1. 打开 [在线版](https://vibeholding.pages.dev) 或本地 `dev`。
2. 在首页点 **进入知识库**，或 `⌘K` 输入工具名（如 `Cursor`、`Supabase`）。
3. 打开条目：看「选型一句话」、地区 / 定价 / 成熟度、说明与排行；右侧或下方看**关联**（平替、常搭配等）。
4. 点 **加入对比**（最多 4 个）→ 侧栏进 **对比**，看差异高亮。
5. 进 **图谱**，搜索设焦点，切换「生态全景 / 替代族」等视图，调邻域跳数。
6. 在详情点 **关注更新** → **情报** 里看「我的更新流」；或看「全部更新」总览。
7. （可选）桌面 Tauri：进 **凭据**，设主密码创建保险库，按条目挂多账号。

## 3. 典型场景

### 场景 A · 从 0 搭一套可上线栈

1. 打开 **方案** → **方案模板**，选接近目标的航路（如「出海 SaaS 速成版」「国内双端 + 微信生态」）。
2. 阅读分层组合与选型理由 / 注意事项。
3. 或打开 **选型向导**（⌘K →「启动选型向导」），按步骤勾选约束，生成可校验的 Stack。
4. 对拿不准的层：进知识库对比候选，或图谱上看平替与常搭配。
5. 满意后写入 **我的技术栈**，后续可再 `vh stack validate`（CLI）做冲突检查。

### 场景 B · 速查某个工具

1. `⌘K` 或顶栏搜索输入名称 / 标签。
2. 打开详情：官网、学习资源、最近复核日、踩坑与笔记（本地）。
3. 关联面板跳到平替 / 依赖 / 国内对标。
4. 需要并排时点「加入对比」。

### 场景 C · 沿图探索生态

1. **图谱** → 搜索设焦点（如 `claude-code`）。
2. 选视图：生态全景看周围；替代族看同类；依赖 DAG 看上下游。
3. 过滤关系分组（替代 / 组合 / 归属…）与可信度（verified / community / inferred）。
4. 点击节点跳回知识库详情。

### 场景 D · 跟上变局

1. **情报** →「全部更新」浏览版本 / 定价 / 政策。
2. 对关心的条目在详情点 **关注更新**。
3. 「我的更新流」只看关注对象；「待确认」处理情报草稿；「待复核」处理过期条目提醒。

### 场景 E · 管好多账号密钥（桌面）

1. 仅 **Tauri 桌面** 显示凭据入口（Web 出于安全默认不含）。
2. 首次设置 **主密码**（≥8 位，无法找回，请牢记）。
3. 解锁后按知识库条目挂多账号字段；复制后注意脱敏与自动锁定（空闲约 5 分钟）。
4. 可导出加密备份（另设导出口令）；切勿把备份或密钥提交进 Git。

## 4. CLI 速查（`vh`）

仓库根目录：

```bash
pnpm vh info                          # 内容库概况
pnpm vh search "cursor" --limit 10
pnpm vh show cursor
pnpm vh related supabase
pnpm vh alt claude-opus               # 替代 / 国内平替
pnpm vh recipe                        # 列出方案模板
pnpm vh recipe show overseas-saas-fast
pnpm vh stack validate path/to/stack.json
pnpm vh intel feeds
pnpm vh intel scrape                  # 抓取订阅 → 草稿候选（不落盘）
```

多数命令支持 `--json`，便于脚本消费。

## 5. 个性化与沉淀

均存**本机**（浏览器 localStorage / 桌面本地），不会进内容仓库：

- **收藏 / 笔记 / 踩坑**
- **关注**（驱动情报「我的更新流」）
- **我的技术栈**、对比列表
- **本地覆盖**：在桌面可编辑条目 / 建边（草稿），正式入库需走 `content/` + `pnpm validate`

贡献公共内容见 [`CONTRIBUTING.md`](../CONTRIBUTING.md) 与 [`content/README.md`](../content/README.md)。

## 6. 主题与密度

- **设置 → 主题**：浅色（宣纸）/ 深色（暖墨）；顶栏太阳 / 月亮图标亦可切换。
- **密度**：舒适 / 紧凑，面向长时间浏览与 power user。

## 7. 常见问题

| 问题 | 说明 |
| --- | --- |
| Web 找不到「凭据」 | 设计如此：凭据仅桌面 / CLI，避免浏览器存敏感材料 |
| 图谱很空或很卡 | 先设焦点 + 降低邻域跳数；大图可开聚类 |
| 对比是空的 | 需在知识库列表或详情点「加入对比」（最多 4 个） |
| 情报「我的更新流」为空 | 先在详情「关注更新」，或先看「全部更新」 |
| 主密码忘了 | 无法找回；只能清库重建（本地数据会丢），故务必牢记或自备加密备份 |
| 内容想改上游 | 改 `content/` → `pnpm validate` → `pnpm gen:content` → 提 PR |

更细的场景说明见上文各节；贡献公共内容见 [`CONTRIBUTING.md`](../CONTRIBUTING.md)。
