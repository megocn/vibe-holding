# Cloudflare Pages / Vercel / Netlify — Web 只读壳部署

静态 SPA，构建产物：`apps/desktop/dist`。

## 通用构建参数

| 项 | 值 |
| --- | --- |
| Node | `22`（见根目录 `.nvmrc`） |
| 包管理 | `pnpm@10`（见 `packageManager`） |
| Install | `pnpm install --frozen-lockfile` |
| Build | `pnpm build:web` |
| Publish / Output | `apps/desktop/dist` |
| SPA fallback | `/*` → `/index.html`（200） |

凭据管家**不会**出现在 Web 部署中（安全边界）。

## Cloudflare Pages

- 仓库已含 `wrangler.toml`（`pages_build_output_dir = "apps/desktop/dist"`）。
- CLI：`pnpm deploy:pages`（需 `wrangler login`）。
- Dashboard：Framework preset 选 None；Build / Output 同上表；环境变量可设 `NODE_VERSION=22`。

## Vercel

见根目录 `vercel.json`（install / build / output / SPA rewrite）。

## Netlify

见根目录 `netlify.toml`（build / publish / SPA redirect）。

## 国内镜像（可选）

若 pnpm 安装较慢，可在构建环境设置：

```bash
npm config set registry https://registry.npmmirror.com
```

或使用平台提供的缓存 / 私有 registry。
