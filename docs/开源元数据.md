## 需你在 GitHub 网页手动完成的检查清单

以下无法仅靠本仓文件 PR 完成：

- [ ] **About**：粘贴上方 Description + Website
- [ ] **Topics**：按推荐最小集或全表勾选
- [ ] **Features → Discussions**：按需开启，分类可设 `content` / `ideas` / `q-a`
- [ ] **把 10 条草稿贴成 Issue**：见 [`GOOD_FIRST_ISSUES.md`](./GOOD_FIRST_ISSUES.md)，打上 `good first issue` + `content`
- [ ] **Labels**：确认存在 `content`、`bug`、`good first issue`（模板已引用）
- [ ] **分支保护 / CI**：`.github/workflows/ci.yml` 已配置；在 Settings 里按团队策略要求 `validate` 通过
- [ ] **勿**在 Description / README / Issues 里贴真实 API Key 或私钥
- [ ] **划清开源边界**：对外介绍时说明选型擂台玩法在 `private/`、不在本 Apache 仓内
